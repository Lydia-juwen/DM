# 一、欧拉路径（Euler Path）与欧拉回路（Euler Circuit）

## 1.1 定义
1）欧拉路径：简单路径，**经过每条边恰好一次**  
2）欧拉回路：闭合的简单路径（起点=终点），经过每条边恰好各一次  
3）欧拉图：存在欧拉回路的图  
4）关系：欧拉回路一定是欧拉路径，反之不成立  
5）注意判断前一定要保证图是连通的  

## 1.2 无向图的欧拉路径判定：存在性判定定理
1）欧拉回路的充要条件：  
连通多重图有欧拉回路 <=> 所有顶点的度数都是偶数  
2）欧拉路径（非回路）的充要条件：  
连通多重图有欧拉路径但没有欧拉回路 <=> 恰好有2个顶点的度数是奇数  

## 1.3 有向图的欧拉路径判定
1）有向欧拉回路的充要条件：  
```
I.弱连通

II.每个顶点的入度=出度
```
2）有向欧拉路径（非回路）的充要条件：  
```
I.弱连通

II.除2个顶点外，其余顶点的入度=出度

III.终点的入度=出度+1，起点的入度=出度-1  
```

## 1.4 欧拉回路的构造算法
1）输入：连通且无奇度顶点的图G  
2）输出：欧拉回路  
3）步骤：  
```
I.任选起点a，随便走，形成一个简单回路circuit，从G中删除这个回路的边

II.在剩下的子图H中找和circuit的公共顶点，从这个顶点出发再走一个新的子回路subcircuit并拼接到circuit里，从G中删除这个回路的边

III.重复步骤II，直到H没有边剩下，最终的circuit就是欧拉回路
```

# 二、哈密顿路径（Hamilton Path）和哈密顿回路（Hamilton Circuit）

## 2.1 定义
1）哈密顿路径：简单路径，**经过每个顶点恰好一次**  
2）哈密顿回路：闭合的简单路径（起点=终点），经过其余每个顶点恰好一次  
3）哈密顿图：存在哈密顿回路的图  
4）关系：哈密顿回路一定是哈密顿路径，反之不成立

## 2.2 充分判定条件
1）狄拉克定理（Dirac）：简单图顶点数n>=3，且每个顶点的度数>=n/2 => 哈密顿图  
2）奥勒定理（Ore）：简单图顶点数n>=3，且任意两个不相邻的顶点u, v满足两者度数和>=n => 哈密顿图  

## 2.3 必要判定条件
哈密顿图 => 对任意非空顶点子集S，图G去掉S后的连通分支<=|S|  

翻译：去掉k个顶点，最多分成k个连通块  

## 2.4 常用推论
1）有度为1的顶点：不可能有哈密顿回路  
2）有度为2的顶点：连接它的两条边必须都在哈密顿回路里  
3）如果有顶点子集S，去掉后连通分支数>|S|，不可能有哈密顿回路（逆否命题）
