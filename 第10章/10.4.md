# 一、路径

## 1.1 定义
从顶点u到v经过的边形成的序列  

## 1.2 分类
1）长度为n的路径：边序列e1, e2, ..., en对应顶点序列x0=u, x1, ..., xn=v  
2）回路（Circuit/Cycle）：起点=终点的路径  
3）简单路径：不重复经过同一条边  

# 二、图的连通性（Connectivity）

## 2.1 无向图的连通性
1）连通图：任意两个不同的顶点之间都存在路径  
2）非连通图：可以被分成多个**极大连通子图**，每个子图叫一个**连通分量**（Connected component）  
3）定理：连通无向图中，任意两点之间都存在简单路径（如果路径有环，删掉环的边就能得到简单路径）  

## 2.2 有向图的连通性
1）强连通（Stronly connected）：任意两个顶点a和b，既有从a到b的路径，也有从b到a的路径  
2）弱连通（Weakly connected）：把有向边改为无向边后，得到的无向图是连通的  
3）关系：强连通 => 弱连通  
4）强连通分量（SCC）：极大的强连通子图  
整个有向图可以拆成多个互不相交的强连通分量  
弱连通分量（WCC）同理  

## 2.3 连通性的量化
用**最少删多少个顶点/多少条边可以让图断开**来度量连通性  
1）点连通度（Vertex connectivity）：k(G)
```
I.点割集（Vertex cut）：删除一组顶点后图变成非连通，这组顶点就叫点割集  

II.点连通度：所有点割集中最小的顶点个数，记为k(G)  
   图本身不连通/只有1个顶点：k(G)=0  
   图连通且有割点/只有2个顶点的完全图K2：k(G)=1  
   n个顶点的完全图Kn：k(G)=n-1  
   一般情况：0<=k(G)<=n-1  

III.割点（Cut vertex）（关节点）：删掉它之后图的连通分量变多，也是大小为1的点割集

IV.k-连通图：如果k(G)>=k，说明至少要删掉k个点才能让图断开，k越大图越稳定  
```
2）边连通度（Edge connectivity）：λ(G)  
```
I.边割集（Edge cut）：删除一组边后图变成非连通，这组边就叫边割集

II.边连通度：所有边割集中最小的边数，记为λ(G)
   图本身不连通/只有1个顶点：λ(G)=0
   n个顶点的完全图Kn：λ(G)=n-1

III.割边（Cut edge）（桥）：删掉它之后图的连通分量变多，也是大小为1的边割集
```
3）关系：点连通度<=边连通度<=图的最小顶点度数
