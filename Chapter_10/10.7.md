# 一、平面图（Planar Graph）

## 1.1 定义
一个图如果能画在平面上，**边与边只在端点处相交（无交叉）**，则称为平面图  
这种画法叫做平面嵌入  

## 1.2 相关术语
1）面/区域（Face/Region）：平面被边切割出的每一块  
2）有界区域（Bounded region）：被边围住的内部区域  
3）无界区域（Unbounded region）：外部无限大的区域，**每个平面图恰有1个**  
4）面的次数deg(R)：围成面R的边数之和，**所有面的次数之和为总边数的2倍**  
5）初等细分（Elementary Subdivision）：把边(u, v)换成(u, w)和(w, v)，加入一个新顶点w（不改变平面性）  
6）同胚（Homeomorphic）：两个图能通过一系列初等细分从同一个图得到  

# 二、欧拉公式（Euler's Formula）

## 2.1 连通平面图
定理：设连通简单平面图G有v个顶点，e条边，r个面（区域），则r=e-v+2  

## 2.2 不连通情形
若有k个连通分量，则r=e-v+k+1  

## 2.3 欧拉公式的推论
1）连通简单平面图，v>=3时，e<=3v-6  
```
推导：  

I.每个面至少由3条边围成 -> ∑deg(R)>=3r

II.∑deg(R)=2e -> 2e>=3r -> r<=2e/3

III.代入欧拉公式r=e-v+2
```
2）连通简单平面图，不含长度为3的环，则e<=2v-4  
3）连通简单平面图存在顶点满足deg(v)<=5  
```
反证：  

若所有deg(v)>=6，则2e>=6v，与推论1中2e<=6v-12矛盾
```
