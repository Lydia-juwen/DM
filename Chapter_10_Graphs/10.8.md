# 一、着色（Coloring）与色数（Chromatic Number）

## 1.1 地图着色规则
有公共边界（长度>0）的两个区域必须涂不同颜色，目标是用最少颜色数完成着色  

## 1.2 对偶图（Dual Graph）
将地图转化为对偶图可以把原问题转化为图论问题  
区域 -> 顶点  
公共边界 -> 边  

## 1.3 着色与色数
1）着色：给每个顶点分配颜色，相邻顶点颜色不同  
2）色数χ(G)：图G着色所需的最少颜色数
3）如何证明χ(G)=n：  
```
I.构造性证明：给出一种用n种颜色的合法着色方案

II.下界证明：证明用n-1种颜色不可能完成（通常使用反证法）
```

## 1.4 四色定理
任意平面图的色数不超过4，即χ(G)<=4  

非平面图的色数可以任意大（如完全图Kn的χ=n）

## 1.5 简单图的色数速查表
```
                         色数χ(G)        备注  

孤立顶点                     1            无边  

无环路径                     2           二分图  

偶圈Cn（n偶）                2           二分图  

奇圈Cn（n奇，n>=3）          3          非二分图  

完全图Kn                    n           每点相邻  

二分图                      2           充要条件
```

# 二、贪心着色算法

## 2.1 步骤
1）排序：按度数降序排列顶点v1, v2, ..., vn  
2）颜色1：从v1开始，给所有不相邻的顶点涂颜色1  
3）颜色2：从未着色顶点中选第一个，给所有不相邻且未着色的顶点涂颜色2  
4）以此类推直到所有顶点着色  

## 2.2 性质
1）贪心算法不一定得到最优色数  
2）最坏情况下，时间复杂度为指数级  
3）近似困难：即使不奢求找到最少颜色数（最优解），只希望找到一个合法且颜色数较少的方案（近似解），也难以做到
