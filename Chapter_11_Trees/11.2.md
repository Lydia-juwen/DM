# 一、二叉搜索树（Binary Search Tree）（BST）

## 1.1 定义
一颗有序的有根二叉树，满足：  
1）每个节点存储一个互异的键值（Key）  
2）任一节点左子树的键值<该节点键值，右子树的键值>该节点键值  

## 1.2 构建
1）第一个插入元素为根节点  
2）后续元素从根开始比较，若小于当前节点则往左走，大于则往右走，直到找到空位作为叶子插入  

## 1.3 查找（Find）和插入（Insert）
n个顶点，最坏情况退化为链，时间复杂度Θ(n)  

平衡BST：高度约为⌈log_2 (n+1)⌉，查找或插入最多比较⌈log_2 (n+1)⌉次，时间复杂度Θ(log n)  

# 二、决策树（Decision Tree）

## 2.1 定义
1）内点：一次决策  
2）分支：该决策的一种可能结果  
3）叶子：最终答案  

## 2.2 用决策树分析排序和查找下界
1）比较排序的决策树是二叉树  
2）n!个排列 -> 叶子>=n!  
```
举例：

用决策树排列3个元素a, b, c

所有可能的排序结果有3!=6种，所有决策树的叶子数>=6
```
3）高度h>=⌈log n!⌉，所以h=Ω(n(log n))（排序下界）  

# 三、前缀码与哈夫曼编码

## 1.1 前缀码（Prefix Code）
任意字符的编码都不是其他字符编码的前缀，防止了产生歧义  
```
举例：

e=0, a=10, t=11 -> 10110只会被解码为ate
```
可用二叉树叶子表示，左分支标0，右分支标1  

## 1.2 哈夫曼编码（Huffman Coding）
1）目标：给定字符及出现频率wi，赋予前缀码使得加权总长最小（出现得越频繁的字符，给它的编码应该越短）  
>min∑(li*wi)，i从1到t；li表示字符i的编码长度（叶深度）

```
举例：

要发的一条消息里只含有A, B, C三个字母，A出现5次，B出现3次，C出现2次

I.方案一（平均主义）：

不管谁出现频率高，都编成2位：A=00, B=01, C=10 -> 总长20b

II.方案二（哈夫曼编码）：

A出现最多，给最短的码：A=0, B=10, C=11 -> 总长5*1+3*2+2*2=15b
```
2）步骤：  
```
I.每个字符建一颗单点树，权值=频率，放入森林

II.取出权值最小的两棵树T1和T2

III.新建根，合为新树，新权值=w(T1)+w(T2)

IV.左子树放权大的，右子树放权小的（也可以反着来）

V.新树放回森林

VI.重复步骤II到V，最后将森林合并为一棵树，得到哈夫曼树
```
