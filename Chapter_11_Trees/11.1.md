# 一、树（Tree）

## 1.1 定义
1）树：连通且无简单回路（Acyclic）（无环）的简单无向图  
2）等价定义：一个无向图是树 <=> 任意两个顶点间存在唯一一条简单路径  
3）森林（Forest）：无简单回路但不连通的无向图称为森林，每个连通分支是一棵树  

## 1.2 性质
1）连通且无环，任意两个顶点间存在唯一一条简单路径  
2）|E|=|V|-1  
3）平面图，区域数r=1（可由性质2和欧拉公式得出）  
4）二分图，色数χ(T)=2  
5）每条边都是割边

# 二、有根树（Rooted Tree）

## 2.1 定义
选定一个顶点作为根，边默认远离根的方向，称为有根树  
同一无根树选择不同的根可以得到不同的有根树  

## 2.2 相关术语
1）父节点（Parent）：距离根更近的邻接点  
2）子节点（Children）：远离根的邻接点  
3）兄弟（Siblings）：有相同父节点的顶点  
4）祖先（Ancestor）：从根到该点路径上的所有顶点（不包含该点）  
5）后代（Descendant）：以该点为祖先的顶点  
6）叶子（Leaf）：无子节点的顶点  
7）内点（Internal Vertex）：至少有一个子节点的顶点  
8）子树（Subtree）：某顶点及其所有后代构成的子图  

# 三、m叉树/二叉树（Binary Tree）

## 3.1 定义
1）m叉树：每个内点至多m个孩子  
2）满m叉树：每个内点恰好m个孩子  
3）二叉树：m=2  

## 3.2 有序有根树
1）每个孩子有顺序，通常从左到右，如二叉树区分左孩子和右孩子  
2）非同构：两颗有序二叉树结构相同但左右互换  

# 四、定理

## 4.1 定理一
n个顶点的树 => n-1条边  
```
证法一（根映射法）：

选根r，其余n-1个顶点各与一条入边对应 => n-1条边
```
```
证法二（欧拉公式）：

I.连通平面图：r=e-n+2

II.树无回路：r=1

III.代入得e=n+1-2=n-1
```
推论：若无向图满足连通、无环、n-1条边，则为树  

## 4.2 定理二：满m叉树顶点数
若满m叉树有i个内点，则总顶底数为n=mi+1  
```
证明：

除根节点外，每个顶点恰是一个内点的孩子 -> i个内点产生mi个非根顶点+根=mi+1
```

## 4.3 定理三：满m叉树衍生公式
n=mi+1，n=i+l（l表示叶子数）  
=>  
i=(n-1)/m，l=n-i=\[(m-1)n+1]/m  

满二叉树：l=i+1  

## 4.4 定理四：m叉树叶子上界
高度为h的m叉树，叶子数<=m^h  
```
证明（归纳法）：

高度1时最多m个叶子

假设高h-1时成立，删根后得m颗高H<=h-1的子树

叶子数l<=m*[m^(h-1)]=m^h
```
推论：h>=⌈log_m l⌉，等号在满叉且平衡时取到
