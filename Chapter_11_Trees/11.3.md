# 一、树的遍历（Traversal）

## 1.1 三种遍历方式
1）前序（Preorder）：根->左子树->右子树  
2）中序（Inorder）：左->根->右  
3）后序（Postorder）：左->右->根  

## 1.2 唯一确定树
1）已知前序+每个节点的孩子数 => 唯一确定树  
```
原理：

I.前序序列的第一个一定是根

II.连续一段父亲->第一个孩子->第一个孩子的第一个孩子->...直到遇见叶子

III.删除该叶子，递归处理剩余序列
```
2）已知前序+中序 => 唯一确定树

原理：

I.前序序列的第一个一定是根

II.在中序里找根A，左边是左子树，右边是右子树

III.在前序里对应出左子树和右子树

# 二、表达式树（Expression Tree）

## 2.1 结构规则
1）叶子：操作数（数字、变量等）  
2）内点：运算符  

## 2.2 三种表达式
1）前缀（Prefix）：对应前序，运算符在前，无括号  
2）中缀（Infix）：对应中序，运算符在中间，需要括号  
3）后缀（Postfix）：对应后序，运算符在后，无括号  

## 2.3 举例
表达式：3*ln(x+1)+a/(x^2)  
1）前缀：+ * 3 ln + x 1 / a ^ x 2
```
          +
     *        /  
  3    ln   a   ^  
      +        x 2  
     x 1
```
